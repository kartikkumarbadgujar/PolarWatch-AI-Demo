# PolarWatch AI — Pipeline Demo

A working, pure-Python demo of the pipeline described in the PolarWatch AI
proposal: **Capture → Detect → Identify → Assess Health → Analyze Anomalies →
Predict Risk → Alert Researchers**.

No trained models are loaded — YOLO/CNN/RNN aren't built yet — so each stage
is implemented as a small synthetic module that produces output shaped the
way the real model's output will be. That lets the full data flow and the
dashboard UX be demoed and reviewed before any training happens. Every score
you see is generated by code in `polarwatch/`, not inference.

## Run it

```bash
python -m venv .venv
.venv\Scripts\activate        # macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

It opens at `http://localhost:8501`. Click **Run Detection Cycle** in the
sidebar repeatedly — one species is scripted to develop an escalating health
concern, so its risk score climbs from **Normal → Monitoring → High Risk →
Critical** over roughly 10–20 cycles, firing automated alerts once it
crosses into High Risk, exactly like the flow in the proposal. **Reset
Simulation** starts a fresh scenario (new species, new station, new random
seed for the run).

## What's in each tab

- **Live Monitoring** — the simulated camera feed with detection boxes,
  the pipeline-stage tracker, the risk gauge and its contributing factors,
  the behavioural anomaly timeline, and the alert log.
- **Population & Health** — estimated colony sizes with a 7-day trend and
  each species' current automated health status.
- **About the Pipeline** — which module stands in for which part of the
  real architecture, and what's simulated vs. real logic.

## Project layout

```
app.py                    Streamlit dashboard (the only UI code — no HTML/CSS/JS)
polarwatch/
  data.py                 Species, stations, detection layout, risk-zone thresholds
  detection.py             Stand-in for the YOLO detector
  health.py                Stand-in for the CNN visual health classifier
  behavior.py               Stand-in for the RNN behavioural anomaly analysis
  risk_engine.py            Real weighted combination into the 0-100 risk score
  alerts.py                 Real threshold logic that fires the alert log
  scene.py                  OpenCV rendering of the camera-feed illustration
  viz.py                    Matplotlib rendering of the risk gauge
  scenario.py                Orchestrates one full pipeline cycle end to end
.streamlit/config.toml     Theme (color palette, no custom CSS)
requirements.txt
```

## Wiring in the real models later

Each simulated module (`detection.py`, `health.py`, `behavior.py`) exposes
the same shape of output a trained model will return — a species + bounding
box + confidence, a 0–100 visual-concern score, a 0–100 anomaly score. To go
from this demo to the real system, swap the body of `SimulatedDetector.detect`,
`HealthAssessor.assess`, and `BehaviorAnalyzer.update` for calls into your
trained YOLO/CNN/RNN models — `risk_engine.py`, `alerts.py`, and `app.py`
don't need to change.
